# AFTERPLAY 1.6.0

- Крупный просмотр повтора по центру окна. Плеер занимает всю доступную ширину, выделение отрезка и заметки находятся под ним. Начальное окно программы увеличено до 1600 × 1000 и адаптируется к экрану.
- Исправлена настройка горячих клавиш: при фокусе в поле глобальная регистрация временно снимается, поэтому сочетание можно ввести без запуска его действия. После сохранения, выхода из поля или потери фокуса клавиши снова работают. Есть автоматическое восстановление при потере связи с интерфейсом.
- Добавлена галочка «Включить автообновление». По умолчанию снята, в том числе при обновлении старой установки. В выключенном состоянии фоновых проверок, загрузок и установок нет. Ручная проверка остаётся доступной. При включении обновление проверяется после запуска и затем раз в час; установка выполняется только при остановленной записи и завершённом экспорте.
- В разделе «Повтор» можно выбрать сохранение MP4 или GIF и длительность GIF от 2 до 15 секунд. Та же кнопка и горячая клавиша сохраняют последние секунды как анимацию. Менять формат нужно при остановленном повторе, затем сохранить настройки и включить повтор.
- Для GIF из видео откройте запись, выберите «Формат экспорта → GIF» и выделите 2–15 секунд. Границы проверяются и в интерфейсе, и перед экспортом.
- GIF: бесконечное повторение, 15 кадров/с, ширина до 720 px с сохранением пропорций, оптимизированная палитра. Звука в GIF нет. GIF видны в библиотеке и экспорте, открываются в центре окна и удаляются в корзину как остальные записи.
- Временный видеобуфер используется и в режиме GIF; готовый MP4 при сохранении GIF не создаётся. Исходное видео при конвертации сохраняется.

## Установка

Скачайте AFTERPLAY-1.6.0-Portable-Win64.zip, распакуйте всю папку и запустите AFTERPLAY.exe.
Переход с 1.5.0 доступен через ручную проверку в настройках. Для установки из распакованного архива полностью закройте AFTERPLAY через «Выйти полностью» и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Update-Existing.ps1 -Target 'C:\AFTERPLAY Portable'
```

Обновлятор проверяет SHA-256, сохраняет резервную копию в backups и сохраняет data, записи и настройки. Автообновление после перехода выключено.

# Changelog

## 1.3.0 — 2026-10-24

- Подхват ранее выбранной игры по пути EXE после перезапуска процесса/окна.
- Проверка GitHub Releases, загрузка проверенного архива и установка с перезапуском,
  резервной копией и откатом при ошибке. Пользовательская папка data сохраняется.
- Стандартная, тёмная и светлая темы с сохранением выбора.
- Единые цвета наведения, нажатия и клавиатурного фокуса для доступных кнопок.
- Кнопки создания ярлыка на рабочем столе и подготовки закрепления на панели задач
  через штатное меню Windows; корректный AppUserModelID ярлыков.
- Переключатель запуска при входе текущего пользователя в Windows.

## 1.2.0 — 2026-10-23

- Захват выбранного окна через Windows Graphics Capture: перекрывающие окна не
  попадают в запись. Можно связать звук с тем же приложением.
- Общая временная шкала картинки и звука: сохранены исходные QPC-метки WASAPI,
  устранено накопление задержки на неполных аудиопакетах. Сегменты сохраняют
  непрерывные временные метки и объединяются без округления длительности аудио.
- Постоянное качество CQ/CRF (по умолчанию 19), VBR и CBR; битрейт 5–200 Мбит/с,
  ограничение пикового битрейта, разрешение до 2160p, 24/30/60/90/120 FPS,
  скорость кодирования, выбор NVENC/CPU и запись курсора.
- H.264 High с B-кадрами; NVENC использует пространственное и временное AQ.
- Исправлена ложная недоступность NVENC: тестовый кадр теперь соответствует
  минимальным требованиям кодировщика NVIDIA.
- Выбор AAC 128–320 кбит/с и ручная поправка синхронизации ±2000 мс.
- При сворачивании или закрытии выбранного окна запись останавливается
  с сообщением. Автоматического переключения на полный экран нет.


- Исправлен запуск после скачивания ZIP и распаковки Проводником Windows:
  .NET-библиотеки с меткой Zone.Identifier проверяются по SHA-256 из комплекта
  и подготавливаются перед загрузкой Python.NET/WebView2.
- Изменяются только перечисленные .NET-компоненты текущего комплекта; системные
  политики Windows и файлы за пределами папки программы не затрагиваются.
- При повреждённой библиотеке подготовка останавливается с понятной ошибкой.

## 1.1.0 — 2026-10-23

- Четыре режима звука: всё устройство, выбранное приложение, исключение приложения, без звука.
- Захват аудио дерева процессов через WASAPI process loopback.
- Выбор буфера: 1, 3, 5, 10, 15, 20 или 30 минут.
- Длительность применяется к сохранению, очистке буфера, проверке места и меню трея.
- Запасной программный кодировщик H.264 для компьютеров без рабочего NVIDIA NVENC.
- Портативная сборка со встроенными Python, FFmpeg и автономным установщиком WebView2.
