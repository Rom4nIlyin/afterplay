# AFTERPLAY

**AFTERPLAY 1.7.0 — локальная видеотека и мгновенные повторы для Windows.** Сохраняйте последние
1–30 минут игры по горячей клавише, выбирайте записываемый звук, отмечайте моменты
и экспортируйте клипы в MP4.

Интерфейс на русском языке. Видео, настройки и библиотека хранятся на компьютере.

## Новое в AFTERPLAY 1.7.0

- Прямой GPU-захват окна и экрана: D3D11 → NVENC без передачи кадров через CPU.
- Профиль «Минимум нагрузки», обновлённый FFmpeg 9.0.2 и единое имя AFTERPLAY.
- В тестовом окне 1440p60 со звуком процесса нагрузка захвата на CPU снизилась с 9,22% до 0,57% всего процессора. Игровой FPS отдельно не измерялся.

- Галерея и список с сохранением выбранного вида.
- Обрезка с кадрами, перетаскиванием границ, подсветкой и просмотром выбранного участка.
- Выбор папки сохранения повторов, экспорта и буфера.
- Исправлено определение версии Windows для звука отдельного приложения.
- Новый логотип Loop, тёмная и светлая темы, панель быстрого сохранения.
- Опциональная автозапись приложений из своего списка `.exe`.
- Сохранение последних минут при закрытии игры.
- Настраиваемые глобальные клавиши сохранения и включения автоматики.
- Автозапуск в трее и встроенный Python без отдельного pythonw.exe.

Подробности и переход с предыдущих версий: [AFTERPLAY 1.5](docs/AFTERPLAY-1.5.md).

Запускайте **AFTERPLAY.exe**.

## Скачать и запустить

Готовая программа находится в разделе **[Releases](https://github.com/Rom4nIlyin/afterplay/releases/latest)**.
Скачивайте файл **`AFTERPLAY-1.7.0-Portable-Win64.zip`** из Assets.
Архивы **Source code** содержат исходники, а не готовую программу.

1. Распакуйте **весь архив** в папку с правом записи, например `D:\AFTERPLAY`.
2. Запустите **`AFTERPLAY.exe`**.
3. Если WebView2 отсутствует, первый запуск установит его из комплекта.
   Установщик автономный: интернет для этого не нужен.
4. При желании создайте ярлыки с помощью `Install-Shortcuts.ps1`.

Python и FFmpeg устанавливать отдельно не требуется. Не запускайте EXE внутри ZIP
и не переносите его отдельно от папки программы. Не используйте `Program Files`:
портативная версия хранит данные рядом с собой.

## Обновления, темы и запуск

В **«Настройках»** доступны:

- **«Проверить обновления»** — сравнение установленной версии с последним стабильным
  релизом этого репозитория на GitHub. Если вышла новая версия, появится кнопка
  **«Обновить и перезапустить»**. Проверяются SHA-256 архива и всех файлов;
  программа закрывается перед заменой, создаёт резервную копию в `backups/update-*`
  и запускается снова. При ошибке замены уже изменённые файлы восстанавливаются.
  Записи и настройки в `data` не заменяются. Перед установкой остановите запись
  и дождитесь экспорта. Проверка и загрузка требуют интернета; вход в GitHub не нужен.
- **«Показывать жёлтую рамку во время записи»** — рамка вокруг захватываемого окна
  или монитора. По умолчанию выключена, в том числе после обновления с 1.3.0.
  Выбор сохраняется; изменение доступно после остановки записи и завершения экспорта.
- **Тема интерфейса:** стандартная, тёмная и светлая. Выбор применяется сразу
  и сохраняется. Доступные кнопки меняют цвета при наведении и нажатии.
- **«Добавить ярлык на рабочий стол»** — ярлык `AFTERPLAY.exe` с иконкой
  приложения и правильной рабочей папкой.
- **«Добавить на панель задач»** — создание ярлыка в меню «Пуск» и открытие его
  расположения. Для завершения нажмите по нему правой кнопкой и выберите
  «Закрепить на панели задач» (в Windows 11 может потребоваться «Показать
  дополнительные параметры»). Windows управляет окончательным закреплением;
  программа не меняет бинарные настройки панели задач.
- **«Запускать автоматически при включении компьютера»** — ярлык в стандартной
  папке автозагрузки текущего пользователя. Запуск происходит после входа в Windows,
  права администратора не требуются. При входе в Windows окно остаётся в трее. Автозапись включается отдельно в настройках.

Список окон обновляется автоматически каждые 3 секунды и при возвращении в окно
AFTERPLAY. Можно открыть игру уже после запуска программы — она появится в списке.
Ранее выбранное приложение подхватывается по пути EXE после перезапуска с новым
PID/HWND. При нескольких копиях той же программы выберите нужную вручную.
Автообновление списка сохраняет выбранный источник и введённые настройки качества;
во время записи источник сам не переключается.

Автообновление впервые появилось в версии 1.3.0. Версию 1.2.0 обновите один раз
распаковкой полного архива с сохранением `data`; следующие версии можно устанавливать
из интерфейса. Не переносите папку приложения после создания ярлыков: если перенесли,
создайте ярлыки и включите автозапуск заново.

## Как сохранить игровой момент

1. Откройте **«Повтор»** и выберите длительность буфера, экран или окно, качество и звук.
2. Нажмите **«Включить повтор»** перед игрой.
3. После нужного момента нажмите **Ctrl + Alt + F10** или кнопку сохранения.
4. Готовое видео появится в библиотеке, разделе «Экспорт» и папке `data/exports`.

Если буфер ещё не заполнился, сохраняется накопленная часть. Сохранение не выключает
запись. Настройки меняются после остановки буфера и завершения текущего сохранения.
Автозапись выполняется только при включённой опции и для приложений из списка. Состояние захвата видно в окне и в подсказке трея. Полный выход останавливает запись.

### Картинка приложения и качество

В поле **«Что записывать»** выберите **«Только окно приложения»**, затем нужное
окно. Список обновляется кнопкой «Обновить список». В режиме звука «Только выбранная
игра / приложение» переключатель связывает звук с этим же окном. Для другого
аудиопроцесса снимите переключатель и выберите его отдельно.

Окна поверх выбранного приложения не записываются. Не сворачивайте источник:
захват останавливается при сворачивании или закрытии. Для игр используйте оконный
режим без рамки. Защищённый контент и некоторые эксклюзивные полноэкранные игры
могут не захватываться. Размер фиксируется при запуске: при изменении размера окна
изображение вписывается с полями; для нового размера включите буфер заново.

Для динамичной игры в **1440p60** начните с **постоянного качества 19**, предела
**80 Мбит/с**, кодировщика **Авто** и скорости **Баланс**. Число CQ/CRF меньше —
качество и размер выше. В VBR задаются средний и максимальный битрейты; CBR удобен,
когда нужен предсказуемый размер. Низкий битрейт ухудшает сложные сцены даже при
хорошем значении качества. H.264 остаётся форматом с потерями.

Разрешение сохраняет пропорции и никогда не увеличивает маленький источник.
90/120 FPS требуют соответствующей частоты источника и запаса производительности;
выбор FPS не создаёт новых кадров игры. При перегрузке снизьте разрешение/FPS.
CPU-кодирование 1440p60 может быть тяжёлым. Статус показывает повторённые и
пропущенные кодировщиком кадры.

Сдвиг звука обычно оставляйте **0 мс**. Отрицательное значение сдвигает звук раньше,
положительное — позже. Настройка предназначена для дополнительной поправки
конкретного источника. Старые уже записанные файлы автоматически не исправляются.

### Режимы звука

| Режим | Что попадает в запись |
| --- | --- |
| **Весь звук устройства** | Все приложения, воспроизводящие звук через выбранное устройство Windows |
| **Только выбранная игра / приложение** | Выбранный процесс и его дочерние процессы |
| **Весь звук, кроме выбранного приложения** | Остальной системный звук со всех устройств, с исключением выбранного дерева процессов |
| **Без звука** | Видео без аудиодорожки |

**Микрофон не записывается.** Для отдельной игры запустите её, обновите список
и выберите именно окно игры, а не Steam или другой лаунчер. После перезапуска игры
перезапустите буфер; при нескольких копиях приложения выберите нужную копию.

Режимы захвата и исключения процесса требуют **Windows build 20348+**, в том числе
Windows 11. На обычной Windows 10 22H2 доступны весь звук устройства и запись без звука.
Неподдерживаемый режим не заменяется автоматически на системный звук.
Защищённое системой аудио может не захватываться.

## Системные требования

- Windows 10 1903+ (build 18362+) или Windows 11, **x64**.
- .NET Framework 4.8 и Microsoft Edge WebView2 Runtime.
- NVIDIA с поддержкой NVENC рекомендуется; при его отсутствии используется CPU.
- Свободное место под буфер и готовые клипы. Чем больше время и битрейт, тем больше нужно места.
- Для игры рекомендуется оконный режим без рамки.

На слабом компьютере выберите 1080p/720p и 30 FPS. Программа не подписана
сертификатом издателя; Windows может показывать предупреждение SmartScreen.
На управляемом рабочем ПК установка WebView2 может требовать прав администратора.

## Библиотека, обрезка и папка сохранения

Кнопки «Галерея» и «Список» находятся над библиотекой. Вид сохраняется при перезапуске.
Откройте видео: кадры на шкале помогают выбрать момент. Перетаскивайте границы или
весь выделенный участок, задавайте точное время и нажмите «Посмотреть выделенное».
В MP4 попадёт подсвеченный участок; исходное видео не изменяется.

В «Настройках» → «Место сохранения записей» выберите папку для новых MP4.
Повторы, обрезанные клипы и буфер будут использовать этот диск. Старые файлы
не перемещаются; библиотека и раздел экспорта помнят прежние пути.
Для изменения папки остановите запись и дождитесь завершения операций.

## Данные и конфиденциальность

| Путь | Содержимое |
| --- | --- |
| `data/exports/` или выбранная папка | Готовые записи и экспортированные клипы |
| `data/library.sqlite3` | Библиотека, теги, заметки, избранное и отметки |
| `data/settings.json` | Настройки и подключённые внешние папки |
| `data/replay-buffer/` или `<выбранная папка>/.afterplay-buffer/` | Временные сегменты активного буфера |
| `data/thumbs/` | Превью |
| `data/logs/` | Журналы |

Папка `data` создаётся при первом запуске. Исходные видео из подключённых папок
не копируются в программу. Для переноса своих данных закройте приложение и скопируйте
его папку целиком; пути к внешним видео на новом ПК подключите заново.

Интерфейс работает через локальный HTTP-сервер на `127.0.0.1` с токеном сеанса.
Загрузка записей в облако не предусмотрена. При проверке и загрузке обновлений
программа обращается к GitHub за публичным релизом; видео и настройки не отправляются. В публичном репозитории и готовом архиве
нет личных видео, базы данных и настроек разработчика.

## Запуск и сборка из исходников

Подробная инструкция: **[docs/BUILD.md](docs/BUILD.md)**.

Для готовой портативной сборки на Windows x64 с Python 3.13:

```powershell
python scripts/build_portable.py
```

Скрипт устанавливает закреплённые зависимости в каталог сборки, компилирует C#-компоненты,
добавляет официальный embeddable Python и автономный WebView2, создаёт ZIP и SHA-256.
Для сборки нужен интернет; для обычного запуска готового архива он не нужен.

### Структура исходников

```text
app.py                   Видеотека, экспорт, локальный API и окно приложения
replay.py                Кольцевой буфер, захват, кодирование и горячая клавиша
capture_media.py         Совместимый захват и общий QPC-таймер аудио/видео
gpu_capture.py           Прямой D3D11-захват и транспорт только звука
video_quality.py         Проверка параметров и настройка кодировщиков
process_audio.py         Выбор процесса/окна и Python-обёртка WASAPI
runtime_trust.py         Проверка и подготовка скачанных .NET-компонентов
ProcessAudio.cs          Захват аудио дерева процессов через Windows API
desktop.py               Трей, значки и поведение закрытия
Launcher.cs              Запуск и проверка WebView2
ReplayNotification.cs    Уведомления без переключения фокуса
ui/                      HTML, CSS, JavaScript и иконки
scripts/                 Сборка и упаковка
docs/                    Инструкции и сведения о проверках
```

## Проверки и ограничения

Версия **1.3.0** исправляет ошибку `Python.Runtime.Loader.Initialize` после скачивания ZIP
и распаковки Проводником Windows. При первом запуске программа проверяет SHA-256
своих .NET-компонентов по `SHA256SUMS.json` и подготавливает их перед загрузкой.
Для обновления закройте приложение и замените файлы из нового полного архива,
сохранив папку `data`. Старые записи и настройки останутся на месте.

Проверены минутный повтор NVENC с импульсами картинки/звука, захват окна и монитора,
режимы качества NVENC/CPU, элементы интерфейса и запуск после распаковки с метками
скачивания. В тесте минутного MP4 отклонение звука от вспышек было от −27 до +43 мс
без накопления задержки. Это измерение тестового окна, а не гарантия для любой игры.

Отдельная чистая виртуальная машина Windows, полный 30-минутный сеанс и запись
непосредственно внутри игры не тестировались. Подробности: **[docs/VERIFICATION.md](docs/VERIFICATION.md)**.

## GIF и просмотр в 1.7.0

Просмотр повтора увеличен и расположен по центру; настройки отрезка и заметки находятся под плеером.
В разделе «Повтор → Сохранять момент как» доступны MP4 и GIF. Для GIF задайте 2–15 секунд, сохраните настройки и включите повтор. При сохранении кнопкой или горячей клавишей будет создана GIF последних секунд, без готового MP4. Временный видеобуфер остаётся необходимым.
Для конвертации части видео откройте запись, выберите формат GIF и выделите отрезок 2–15 секунд. GIF создаются без звука, 15 кадров/с, ширина до 720 px, с повторением по кругу. Файлы доступны в библиотеке и экспорте.
«Настройки → Включить автообновление» по умолчанию выключено. При выключенной галочке программа не проверяет и не устанавливает обновления в фоне. Кнопка ручной проверки работает всегда. При включении установка откладывается до окончания записи и экспорта.
Для изменения горячих клавиш нажмите поле, введите сочетание и нажмите «Сохранить». Во время ввода глобальные действия временно отключены; при выходе из поля они восстанавливаются.
