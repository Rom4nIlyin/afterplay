# AFTERPLAY 1.5.0

Меньше нагрузки во время фоновой записи последних минут.

- На NVIDIA окно или монитор захватываются в D3D11 и передаются прямо в NVENC. Кадры больше не копируются через Python, не преобразуются на CPU и не загружаются обратно на GPU.
- Неизменившийся рабочий стол записывается через Desktop Duplication с таймером повторения кадров; окно и масштабирование используют Windows Graphics Capture.
- Масштабирование выполняется на GPU. Разрешение и частота записи сохраняются.
- Новый профиль «Минимум нагрузки»: NVENC P1, нулевая задержка выдачи, без lookahead, AQ, B-кадров и дополнительного прохода. Постоянное качество CQ 19 остаётся доступным; профили «Баланс» и «Больше сжатие» сохранены.
- В настройках повтора появился выбор GPU / совместимого захвата. Если прямой путь недоступен, программа показывает причину перехода в совместимый режим.
- FFmpeg обновлён до 9.0.2; его загрузка при сборке проверяется по закреплённой SHA-256.
- Полностью единое имя AFTERPLAY: один AFTERPLAY.exe, уведомления, обновлятор, значки, служебные компоненты и документация.
- Обновлятор сохраняет резервную копию и убирает устаревшие файлы из каталога предыдущей версии. Изменённые пользователем файлы остаются на месте.

На RTX 3080 в одинаковом движущемся тестовом окне 2560×1440, 60 FPS со звуком отдельного процесса суммарная нагрузка захвата на CPU снизилась с 9,22% до 0,57% всего 16-поточного процессора (около 94%). Это замер захвата, не обещание конкретного прироста FPS в игре. Сохранённые MP4 полностью декодированы; максимальное расхождение десяти звуковых/световых импульсов — 70 мс. Игра не запускалась.

## Установка и переход с 1.4.1

Скачайте **AFTERPLAY-1.5.0-Portable-Win64.zip**, распакуйте всю папку и запустите **AFTERPLAY.exe**. Python, FFmpeg и установщик WebView2 входят в комплект.

Для перехода с 1.4.1 и более ранних версий полностью закройте программу, распакуйте новый архив в отдельную папку и выполните из неё:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Update-Existing.ps1 -Target 'C:\AFTERPLAY Portable'
```

Скрипт проверит файлы, обновит прежнюю папку, сохранит `data`, библиотеку, записи и настройки, создаст резервную копию в `backups/update-*` и перезапустит AFTERPLAY. Старый встроенный проверяющий модуль требует прежний набор файлов, поэтому для этого перехода нужен данный скрипт. Следующие обновления можно устанавливать из настроек AFTERPLAY.

Для наименьшей нагрузки выберите «Способ захвата → GPU», «Кодировщик → NVIDIA NVENC» и «Скорость кодирования → Минимум нагрузки». Длительность буфера не нужно уменьшать.
