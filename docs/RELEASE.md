# AFTERPLAY 1.11.0

Более компактный набор оформления, обучение по интерфейсу и удобный запуск в трее.

- **Шесть разных тем:** Obsidian, Frosted Glass, Aurora, Ember, Mist и Paper. Похожие варианты удалены; сохранённые оформления и импортируемые наборы автоматически получают ближайшую оставшуюся тему. Собственные цвета, фоны, звуки и остальные параметры сохраняются.
- **Обучение:** при первом открытии предлагается тур из семи шагов с кнопкой «Пропустить». Подсвечиваются вкладка в меню и нужный блок; подсказка не закрывает элементы. Повторный запуск: **Настройки → Пройти обучение**. Есть отдельный шаг об оформлении.
- **Запуск:** для новой установки автозапуск с Windows и сворачивание в трей включены по умолчанию. При автозапуске окно скрыто; существующий выбор пользователя сохраняется.
- **Просмотр:** в полном экране убрана общая полоса под кнопками. У кнопки скорости есть собственный фон; меню открывается выше дорожки с зазором.
- **Настройки:** подключённые папки находятся в карточке «Библиотека и папки». Сочетание «Включить / выключить автозапись» удалено; остальные горячие клавиши сохраняются. Сохранение последних минут при выходе из игры по умолчанию выключено.

## Установка и обновление

Скачайте `AFTERPLAY-1.11.0-Portable-Win64.zip` из Assets и распакуйте весь архив. Для новой установки запустите `AFTERPLAY.exe`.

Для обновления используйте **Настройки → Проверить обновления** либо полностью выйдите из AFTERPLAY через меню трея и запустите из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор создаёт резервную копию и сохраняет библиотеку, настройки и записи. При другом расположении программы укажите его через `-Target`.

Контрольная сумма находится в соседнем файле `.zip.sha256`.
