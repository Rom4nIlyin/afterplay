# AFTERPLAY 1.12.0

Новый интерфейс Onyx Cinema и отмена экспорта клипов.

- **Onyx Cinema:** крупное превью, карточки или список, сведения о выбранной записи, пять палитр — Cinema, Onyx, Ocean, Ember и Rose. Можно задать свои цвета и выбрать одну из четырёх иллюстраций бокового меню. Исходный логотип использует цвет оформления. Классический интерфейс доступен в том же разделе.
- **Монтаж:** обновлённые вкладки, таймлайн и управление звуком. Ctrl+Z отменяет изменение обрезки, Ctrl+Shift+Z возвращает его, I и O задают границы в текущей позиции. Несохранённые заметки защищены от случайного закрытия.
- **Быстрые действия:** Ctrl+K открывает поиск команд. Поиск записей сохраняет фокус при вводе. Анимации можно сделать плавными, выразительными или отключить; системное уменьшение движения учитывается.
- **Профиль в шапке:** справа вверху видно выбранный профиль, а при автозаписи — её активный профиль. Нажатие открывает параметры записи. Прежние темы интерфейса показываются только в классическом дизайне.
- **Отмена экспорта:** кнопка «Отменить» в панели прогресса останавливает выбранный MP4 или GIF и убирает недописанный файл. Исходная запись и параллельные экспорты сохраняются. Отменённая задача не показывает окно готового клипа.
- Исправлены лишняя рамка поиска, скрытая нижняя кнопка экспорта и риск сохранения устаревших заметок при переключении избранного. Обучение учитывает новый дизайн.

Настройки, библиотека, заметки и горячие клавиши сохраняются. Автообновление не включается при обновлении. Пользовательские видео, настройки и локальные резервные копии в релиз не включены.

## Установка и обновление

Скачайте `AFTERPLAY-1.12.0-Portable-Win64.zip` из Assets и распакуйте **весь архив** в новую папку. Для новой установки запустите `AFTERPLAY.exe`.

Для обновления используйте **Настройки → Проверить обновления** либо полностью выйдите из AFTERPLAY через меню трея и запустите из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор создаёт резервную копию и сохраняет библиотеку, настройки и записи. При другом расположении программы укажите его через `-Target`.

Контрольная сумма находится в соседнем файле `.zip.sha256`.
