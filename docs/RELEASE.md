# AFTERPLAY 1.9.0

Обновлённый просмотр и монтаж, профили записи и отдельные звуковые дорожки.

- Простой просмотр видео; кнопка «Монтаж» открывает дорожку и вкладки «Обрезка», «Звук», «Экспорт» и «Заметки».
- Профили записи редактируются прямо на странице «Повтор». По умолчанию записываются весь экран и звук устройства; для экранного профиля .exe необязателен. Зелёная кнопка сохраняет параметры выбранного профиля.
- Покадровый просмотр стрелками ← / →, масштабируемая звуковая волна и миниатюры дорожки с сохранением пропорций.
- Таймер остаётся видимым при покадровом просмотре. Окно монтажа использует доступную ширину; элементы управления и шрифты увеличены.
- Режим «Игра + Discord / чат · отдельно»: общий микс, игра и чат. В монтаже дорожки включаются отдельно, имеют свою громкость и могут использоваться при экспорте.
- Метки во время записи через кнопку и трей; отдельная необязательная клавиша для отметки момента.
- Встроенный Inter, мягкая подсветка кнопок за курсором и раскрытие выпадающих списков. Поля выбора и оба ползунка границ не масштабируются при нажатии и наведении.

Существующие сочетания клавиш, темы, папки, библиотека и записи сохраняются.
Автозапись по-прежнему включается отдельно. Микрофон не записывается.

## Установка и обновление

Скачайте `AFTERPLAY-1.9.0-Portable-Win64.zip` из Assets и распакуйте весь архив.
Для новой установки запустите `AFTERPLAY.exe`.

Для обновления полностью выйдите из старого AFTERPLAY через меню трея и запустите из новой папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор создаёт резервную копию и сохраняет пользовательские данные. Укажите свой путь через `-Target`, если программа находится в другой папке.
С версии 1.8.4 обновление также доступно из настроек приложения. Для более ранних версий используйте приведённый скрипт.

SHA-256 находится в соседнем файле `.zip.sha256`. Подробности функций: [руководство](https://github.com/Rom4nIlyin/afterplay/blob/main/docs/STUDIO.md).
Проверки и их границы: [VERIFICATION.md](https://github.com/Rom4nIlyin/afterplay/blob/main/docs/VERIFICATION.md).
