# AFTERPLAY 1.16.1

Windows 10: живое видео окна игры и раздельный звук; клавиша микрофона.

- **Windows 10: запись окна игры больше не застывает на первом кадре.** Раньше в файле был звук и один неподвижный кадр. Теперь окно снимается с экрана по своим координатам, без жёлтой рамки. Окна поверх игры тоже попадут в запись; если кадр чёрный — переключите игру в режим «окно без рамки».
- **Звук отдельных приложений на Windows 10 версии 2004 и новее:** «Только игра», «Всё кроме игры» и «Игра и чат отдельно» (игра и Discord на отдельных дорожках) больше не требуют Windows 11.
- **Клавиша «Выключить или включить микрофон»** в **Настройки → Горячие клавиши**. Вместо голоса пишется тишина, дорожка не пропадает; Discord и Windows не затрагиваются. После перезапуска программы микрофон снова включён.

## Установка и обновление

Скачай `AFTERPLAY-1.16.1-Portable-Win64.zip` из Assets. После остановки записи обнови программу через **Настройки → Обновления** либо запусти из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор сохраняет пользовательские файлы и создаёт резервную копию. Сверь архив с файлом `.zip.sha256`.
