# AFTERPLAY 1.4.1

Game Clips теперь называется AFTERPLAY: выбранный логотип Loop, тёмная и светлая темы.

- Библиотека в виде галереи или списка; выбор сохраняется.
- Наглядная обрезка: реальные кадры, выделенный участок, перетаскиваемые границы и просмотр выделения. Исходник сохраняется.
- Выбор папки новых записей и экспорта; временный буфер использует тот же диск. Старые видео остаются на месте.
- Опциональный автоматический запуск повтора для своего списка игр и приложений; сохранение последних минут при закрытии.
- Настраиваемые глобальные сочетания сохранения и включения автоматики с проверкой конфликтов.
- Вход в Windows запускает приложение в трее.
- Python встроен в AFTERPLAY.exe с фирменной иконкой. FFmpeg и WebView2 остаются отдельными дочерними процессами; Windows самостоятельно отображает ресурсы.
- Исправлена ложная ошибка Windows 11 при захвате звука отдельного приложения: манифест совместимости и проверка реальной версии Windows.

Скачайте **AFTERPLAY-1.4.1-Portable-Win64.zip**, распакуйте всю папку и запустите **AFTERPLAY.exe**. Python, FFmpeg и автономный WebView2 входят в комплект. Source code содержит исходники.

Для обновления старой версии закройте приложение и распакуйте новый архив в прежнюю папку с сохранением своей папки **data**. Не удаляйте data: в ней библиотека, настройки и записи по умолчанию. Следующие обновления доступны из настроек AFTERPLAY. Старый Game Clips.exe сохранён для совместимости ярлыков.

Автоматика выключена по умолчанию и настраивается в разделе «Автозапись игр и приложений». Она включает буфер последних 1–30 минут; полная непрерывная запись сеанса не предусмотрена. Проверено на настоящем тестовом окне, без запуска игры.
