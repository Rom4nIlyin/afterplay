# AFTERPLAY 1.14.0

Оценка размера записи, удобное удаление видео и более плотный интерфейс.

- **Примерный размер файла:** пересчёт до сохранения профиля с учётом длительности, видео- и аудиобитрейта, отдельных дорожек и микрофона. Для CQ/CRF показан приблизительный диапазон по разрешению, FPS, качеству, кодировщику, пресету и пределу битрейта. Для GIF используются его выходные параметры. Диапазоны зависят от сцены и не являются гарантией размера.
- **Удаление видео:** корзина на каждой карточке, в галерее и списке. Диалог предлагает переместить исходный файл в корзину Windows или удалить навсегда, минуя корзину. В нём показаны имя и путь; безвозвратное удаление явно обозначено.
- **Чистые имена экспорта:** MP4, GIF и монтаж сохраняются под введённым названием, без даты и случайных символов. Совпадающие имена получают понятный номер `(2)`, `(3)`; существующие файлы сохраняются. Одновременные задачи резервируют разные имена.
- **Настройки без пустых рядов:** карточки заполняют две колонки по содержимому, при сужении окна переходят в одну. Кнопки очистки горячих клавиш стоят рядом с полями и отделены от сохранения.
- **GitHub:** кнопка открывает репозиторий; в настройках рядом находится копируемая ссылка со значком копирования внутри поля.
- **Карточки и верхняя панель:** профиль не перекрывает запись, дублирующая галочка убрана, корзина выровнена под троеточием. Сохранение повтора обозначено простой круговой стрелкой.
- **Рыся:** сохранён прежний внешний вид. Умывание использует исходные корректные позы с одной и той же поднятой и облизываемой передней лапой; ошибочные кадры исключены.

## Установка и обновление

Скачай `AFTERPLAY-1.14.0-Portable-Win64.zip` из Assets и распакуй архив целиком. Для новой установки запусти `AFTERPLAY.exe`. Для обновления используй **Настройки → Проверить обновления** или из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Перед обновлением полностью выйди из AFTERPLAY. Установщик сохраняет записи и настройки и создаёт резервную копию. SHA-256 находится в соседнем файле `.zip.sha256`.

Проверены экспорт на временных исходниках, выбор удаления, отмена и ошибки, адаптивность интерфейса и запуск WebView2. Реальные пользовательские видео в тестах не удалялись. Игровая точность диапазонов размера, новая игровая сессия и физический микрофон отдельно не проверялись.
