# AFTERPLAY 1.14.2

Запись и повторы продолжаются при тишине, отключении или зависании микрофона.

- **Независимая запись видео:** микрофон работает в отдельном процессе. Недостающий звук заменяется тишиной, а устройство автоматически переподключается. Зависший драйвер больше не задерживает запуск и сохранение видео.
- **Мьют микрофона:** физически выключенный микрофон не останавливает обычную запись и повторы. Мьют Discord действует внутри Discord и не синхронизируется с отдельным микрофоном AFTERPLAY.
- **Запуск автозаписи:** исправлена COM-ошибка захвата звука приложения. Аудиоклиент создаётся, используется и освобождается в одном выделенном MTA-потоке.
- **Повторы на неподвижном изображении:** обновлён FFmpeg и включено повторение кадров GPU-захвата. Статичная сцена продолжает заполнять буфер; проверка настоящего отставания захвата сохранена.
- **Параллельный поиск аудиоприложений:** устранена гонка типов Windows API между интерфейсом и автоматическим наблюдением.
- Очистка и выравнивание голоса RNNoise из 1.14.1 сохранены. Модель обрабатывает звук локально.

## Установка и обновление

Скачай `AFTERPLAY-1.14.2-Portable-Win64.zip` из Assets и распакуй архив целиком. Для новой установки запусти `AFTERPLAY.exe`. Для обновления используй **Настройки → Проверить обновления** или из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Перед обновлением полностью выйди из AFTERPLAY. Обновлятор сохраняет записи и настройки и создаёт резервную копию. SHA-256 находится в соседнем файле `.zip.sha256`.

Проверены 206 Python-тестов, десять JavaScript-наборов и шесть сценариев интерфейса. В настоящем захвате тестового окна сохранены обычная запись и пять повторов во время тишины, отсутствия аудиопакетов, недоступности и зависания микрофона; все файлы полностью декодированы. Физический переключатель и мьют в интерфейсе Discord отдельно не переключались. Игра и влияние на игровой FPS для этого релиза не проверялись.

[Проверки и ограничения](https://github.com/Rom4nIlyin/afterplay/blob/main/docs/VERIFICATION.md).
