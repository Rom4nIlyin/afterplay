# AFTERPLAY 1.14.3

Исправлена синхронизация настройки жёлтой рамки захвата между профилями записи и общими настройками.

- **Одна настройка для всех профилей:** переключатель «Показывать жёлтую рамку во время записи» теперь управляет общим параметром `capture_border`. При выборе другого профиля значение больше не перезаписывается сохранённой копией.
- **Старые профили:** при запуске AFTERPLAY удаляет устаревшие значения `capture_border` из профилей. Другие настройки и записи сохраняются.
- **Новые профили и автозапись:** настройка рамки не копируется в профиль и не переопределяется при автоматическом захвате выбранного окна.
- **Проверки:** добавлен регрессионный тест для миграции старых профилей, ручного переключения и сохранения параметра.

**Ограничение:** эта версия исправляет рассинхронизацию настроек. Если Windows Graphics Capture запрещает захват без системной жёлтой рамки, она может оставаться видимой даже при выключенном переключателе. Это ограничение Windows требует отдельной диагностики на соответствующем компьютере.

## Установка и обновление

Скачай `AFTERPLAY-1.14.3-Portable-Win64.zip` из Assets и распакуй архив целиком. Для новой установки запусти `AFTERPLAY.exe`. Для обновления используй **Настройки → Проверить обновления** или из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Перед обновлением полностью выйди из AFTERPLAY. Обновлятор сохраняет записи и настройки и создаёт резервную копию. SHA-256 архива находится в соседнем файле `.zip.sha256`.
