# AFTERPLAY 1.14.4

Убрана пользовательская настройка системной рамки захвата. На Windows 10 AFTERPLAY больше не создаёт Windows Graphics Capture-сессии, которые могут показывать жёлтое выделение.

- **Упрощённые настройки:** переключатель рамки удалён. Старое значение автоматически очищается из portable-файла настроек и профилей.
- **Windows 10, запись отдельного окна:** для обычной записи и повтора применяется совместимый захват GDI/PrintWindow, не вызывающий системное выделение WGC.
- **Windows 10, запись экрана:** аппаратный DXGI Desktop Duplication по возможности остаётся доступен, без WGC.
- **Windows 11:** сохранены прежние способы захвата, но запрос на показ рамки больше никогда не включается из настроек AFTERPLAY.
- **Профили:** не требуют изменения; существующие видеозаписи и библиотека сохраняются.

**Важно:** GDI/PrintWindow не гарантирует захват всех игр. DirectX-игра может давать чёрное видео или пониженный FPS; необходимо протестировать 20–30 секунд записи Gloria Victis на Windows 10. При несовместимости используйте запись экрана через DXGI (с захватом других открытых окон). Это осознанное ограничение ради отсутствия системной рамки.

## Установка и обновление

Скачай `AFTERPLAY-1.14.4-Portable-Win64.zip` из Assets. После остановки записи обнови программу через **Настройки → Проверить обновления** либо запусти из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор сохраняет пользовательские файлы и создаёт резервную копию. Сверь архив с файлом `.zip.sha256`.
