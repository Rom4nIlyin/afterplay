# AFTERPLAY 1.15.3

Корейский язык интерфейса и полный английский перевод нового экспорта.

- **한국어:** Настройки → Общие → Язык интерфейса → 한국어. Переведены все экраны, ошибки и меню в трее.
- **English:** переведено всё новое из 1.15.2 — качество экспорта, подсказки Discord, GIF, подсказки клавиш.
- **Фразы с числами и даты** переводятся целиком, с правильным порядком слов для каждого языка.

## Установка и обновление

Скачай `AFTERPLAY-1.15.3-Portable-Win64.zip` из Assets. После остановки записи обнови программу через **Настройки → Обновления** либо запусти из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор сохраняет пользовательские файлы и создаёт резервную копию. Сверь архив с файлом `.zip.sha256`.
