# AFTERPLAY 1.10.3

Обычная запись и мгновенный повтор теперь доступны отдельно и могут работать одновременно.

- **Обычная запись:** «Включить запись» начинает сессию, «Отключить запись» сохраняет всё видео в MP4. Можно записывать час и дольше, пока хватает места на диске.
- **Повтор:** «Включить повтор» запускает буфер последних X минут. Прежняя горячая клавиша сохраняет повтор и не прерывает обычную запись. Для обычной записи можно назначить отдельное сочетание в настройках.
- **Просмотр:** пробел и клик по видео запускают воспроизведение и ставят на паузу. F переключает полный экран. Полноэкранная панель и курсор скрываются через 1,5 секунды бездействия, при уходе указателя или потере фокуса.
- **Точные кадры:** устранено мелькание обычного видео при шаге по кадрам; точный кадр и таймер доступны в полном экране.
- **Профили:** запуск недоступного приложения больше не меняет профили. Профиль экрана по умолчанию защищён от замены профилем игры, прежнее повреждение исправляется при запуске. Параметры профиля сохраняются зелёной кнопкой.
- **Надёжность:** при ошибке финального сохранения сегменты обычной записи остаются доступны для повторной попытки.

Горячие клавиши, остальные профили, оформление, библиотека и записи сохраняются.

## Установка и обновление

Скачайте `AFTERPLAY-1.10.3-Portable-Win64.zip` из Assets и распакуйте весь архив. Для новой установки запустите `AFTERPLAY.exe`.

Для обновления используйте **Настройки → Проверить обновления** либо полностью выйдите из AFTERPLAY через меню трея и запустите из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор создаёт резервную копию и сохраняет пользовательские данные. При другом расположении программы укажите его через `-Target`. Не копируйте архив поверх работающего AFTERPLAY вручную.

Контрольная сумма находится в соседнем файле `.zip.sha256`.
