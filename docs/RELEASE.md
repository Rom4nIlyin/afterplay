# AFTERPLAY 1.14.1

Чистый и ровный голос в новых записях.

- **Нейросетевое шумоподавление RNNoise:** уменьшает фоновый шум микрофона, включая гул. Модель входит в portable-архив; обработка работает на компьютере без интернета.
- **Более ровная речь:** плавная регулировка усиления, компрессор и ограничитель пиков. В паузах усиление не растёт. Настройка громкости применяется после обработки, 0% остаётся полным отключением звука.
- **Управление в профиле:** «Повторы → Микрофон → Чистый и ровный голос». Очистка включена по умолчанию, её можно отключить отдельно для каждого профиля. Сам микрофон по-прежнему включается по желанию.
- **Общий звук и отдельная дорожка:** очистка применяется до смешивания, к новым обычным записям и повторам. Существующие видео остаются без изменений.
- **Синхронизация и окончание записи:** компенсируется задержка обработки, сохраняются точные временные метки и длительность после пересчёта частоты микрофона; остаток обработки дописывается до закрытия записи.

## Установка и обновление

Скачай `AFTERPLAY-1.14.1-Portable-Win64.zip` из Assets и распакуй архив целиком. Для новой установки запусти `AFTERPLAY.exe`. Для обновления используй **Настройки → Проверить обновления** или из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Перед обновлением полностью выйди из AFTERPLAY. Установщик сохраняет записи и настройки и создаёт резервную копию. SHA-256 находится в соседнем файле `.zip.sha256`.

Проверены 194 Python-теста, десять JavaScript-наборов, шесть сценариев интерфейса, открытие физического микрофона и точность временной шкалы. Качество именно твоего живого голоса и шумов в игре ещё нужно оценить на короткой новой записи. Другие голоса, сильное эхо и громкие звуки поверх речи могут остаться.
