# AFTERPLAY 1.15.5

Проверка папок библиотеки — только при открытом окне.

- **В трее и свёрнутом виде** AFTERPLAY больше не просматривает папки с видео — диск и процессор не заняты.
- **При разворачивании окна** переименованные, перемещённые и новые видео подхватываются сразу.
- Проверка идёт в фоне и не задерживает интерфейс: даже при индексации десятков новых видео ответы интерфейсу — миллисекунды.

## Установка и обновление

Скачай `AFTERPLAY-1.15.5-Portable-Win64.zip` из Assets. После остановки записи обнови программу через **Настройки → Обновления** либо запусти из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор сохраняет пользовательские файлы и создаёт резервную копию. Сверь архив с файлом `.zip.sha256`.

[Проверки и ограничения](https://github.com/Rom4nIlyin/afterplay/blob/main/docs/VERIFICATION.md).
