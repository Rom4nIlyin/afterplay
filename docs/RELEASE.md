# AFTERPLAY 1.15.1

Исправления по отзывам после 1.15.0.

- **Язык интерфейса снова можно выбрать:** Настройки → Общие → Язык интерфейса → Русский / English. Переведены все экраны нового интерфейса, выбор сохраняется после перезапуска.
- **Библиотека без «призраков»:** видео, удалённые или перемещённые вне AFTERPLAY, сами исчезают из библиотеки. Записи с отключённого диска остаются до его возвращения. Запись без файла удаляется кнопкой «Удалить» без ошибки.
- **Экспорт не съедает память:** повторные нажатия больше не запускают несколько экспортов одновременно; прогресс виден сразу после нажатия.
- **Диспетчер задач:** захват микрофона и системного звука остаётся в отдельных процессах для надёжности, но они называются AFTERPLAY и сгруппированы с программой. Процессов Python и окон консоли больше нет.
- **Просмотр:** пауза срабатывает с первого клика мышью, в том числе по самому значку. Стрелки ← → листают по одному кадру, как в монтаже, Shift + стрелки — по 5 секунд; рядом с паузой появились кнопки «Кадр назад» и «Кадр вперёд».
- **Удаление:** в окне подтверждения можно выбрать «В корзину» (по умолчанию) или «Удалить навсегда».
- **Экспорт:** после завершения кнопки «Копировать файл» и «Показать в папке» больше не выходят за край панели.

## Установка и обновление

Скачай `AFTERPLAY-1.15.1-Portable-Win64.zip` из Assets. После остановки записи обнови программу через **Настройки → Обновления** либо запусти из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор сохраняет пользовательские файлы и создаёт резервную копию. Сверь архив с файлом `.zip.sha256`.
