# AFTERPLAY 1.13.6

Удобнее монтаж, устойчивее запись и верхняя панель в стиле AFTERPLAY.

- **Обучение — один раз:** повторный запуск программы больше не открывает тур, даже если закрыть приложение посреди обучения. Тур можно повторить из настроек.
- **Регулировка редактора:** перетаскивай разделитель между просмотром и дорожкой, чтобы распределить высоту. Положение сохраняется между запусками.
- **Стабильная точка просмотра:** перенос и изменение краёв фрагментов не перемещают установленный курсор. Для экспорта монтажа используется общая кнопка; дубликаты удалены.
- **Discord и микрофон можно подключить позже:** запись и повтор начинаются без отсутствующих источников. При появлении или переподключении они автоматически добавляются к своим дорожкам без перезапуска видео. Пока источника нет, в дорожке тишина. Микрофон должен быть включён в профиле.
- **Сохранение звука:** при остановке записи дописывается отложенный конец аудиодорожек. Исправлена ошибка проверки их длительности.
- **Новая верхняя панель:** оформление следует выбранной палитре, собственные кнопки окна и индикатор записи с таймером. Панель доступна над редактором и диалогами; при полноэкранном просмотре скрывается. Сохранены перетаскивание, двойной щелчок, изменение размера и разворачивание в рабочую область монитора.
- **Аккуратные ползунки:** тонкие округлые полосы прокрутки в цвете темы, без стандартных серых стрелок.
- **Правильное сворачивание:** кнопка «Свернуть» оставляет AFTERPLAY на панели задач. Поведение крестика выбирается отдельно в настройках, включая скрытие в трей.
- **Обновления по HTTPS:** проверка сертификатов использует Windows CryptoAPI, включая построение цепочки промежуточных сертификатов. Проверка сертификата и имени сервера остаётся обязательной.

Настройки, библиотека, записи и профили сохраняются. Личные видео, настройки и резервные копии в дистрибутив не включаются.

## Установка и обновление

Скачай `AFTERPLAY-1.13.6-Portable-Win64.zip` из Assets и распакуй **весь архив** в новую папку. Для новой установки запусти `AFTERPLAY.exe`.

Для обновления используй **Настройки → Проверить обновления**. Если старая версия выдаёт `CERTIFICATE_VERIFY_FAILED`, один раз обнови её из полного ZIP: полностью выйди из AFTERPLAY через меню трея и запусти из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

При другом расположении программы укажи его через `-Target`. Обновлятор создаёт резервную копию и сохраняет пользовательские данные. SHA-256 архива находится в соседнем файле `.zip.sha256`.

Проверены 169 Python-тестов, девять JavaScript-наборов, нативный WebView2 и поведение окна. Захват тестового окна через WGC и D3D11/NVENC проверен с отсутствующим микрофоном, поздним подключением и перезапуском процесса чата. Физическое переподключение USB-микрофона, исходный компьютер с SSL-ошибкой и игровые FPS отдельно не проверялись.
