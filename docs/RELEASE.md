# AFTERPLAY 1.8.4

Portable-папка стала аккуратнее: в корне находятся `AFTERPLAY.exe` и краткая
инструкция; компоненты приложения, UI, Python, FFmpeg и обновлятор собраны в
`app`, руководство и лицензии — в `docs`. Исходники C# не входят в готовый архив.
Папки `data` и `backups` сохраняют прежние места.

Записи, библиотека, темы, настройки и горячие клавиши сохраняются при миграции.
Старые неизменённые компоненты переносятся в резервную копию. Изменённые вручную
и неизвестные файлы сохраняются на месте. Пустые старые служебные папки убираются.
При ошибке замены прежние файлы восстанавливаются.

## Переход с 1.8.3 и более ранних версий

Это разовый переход через скрипт из нового архива. Старый встроенный обновлятор
не принимает новую структуру; он отклонит архив до установки.

1. Скачайте `AFTERPLAY-1.8.4-Portable-Win64.zip` и распакуйте в отдельную папку.
2. Полностью закройте AFTERPLAY через меню трея, дождавшись сохранения.
3. В PowerShell из новой папки выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Укажите свой путь через `-Target`, если программа находится в другой папке.
Не копируйте новый архив поверх прежней установки вручную. Начиная с 1.8.4
последующие встроенные обновления поддерживают новую структуру.

Новая установка: распакуйте весь архив и запустите `AFTERPLAY.exe`.
