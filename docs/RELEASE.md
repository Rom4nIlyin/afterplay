# AFTERPLAY 1.7.0

- Дорожка выбора отрезка масштабируется колесом мыши относительно курсора. Shift + колесо и нижний ползунок прокручивают увеличенный участок. Кнопки «К выделению» и «Вся дорожка» позволяют быстро сменить масштаб. Зум не изменяет границы выделения; кадры дорожки загружаются для видимого диапазона.
- В просмотре видео и GIF добавлена кнопка «Открыть в папке»: Проводник открывает папку и выделяет исходный файл.
- Боковые кнопки мыши «Назад / Вперёд» переключают посещённые разделы и просмотры внутри программы, как история браузера. Поддерживаются события мыши и системные команды Browser Back / Forward. Системных перехватчиков мыши нет.
- «Проверить обновления» получает только информацию о новой версии. При наличии обновления появляется кнопка «Скачать и установить обновление». Загрузка, проверка SHA-256, резервное копирование, замена файлов и перезапуск начинаются после её нажатия. Настройка автообновления остаётся отдельной и по умолчанию выключена.
- Добавлены повторные попытки загрузки компонентов при временных сетевых ошибках во время сборки.
- Исходники проекта теперь под MIT по разрешению владельца. Лицензии сторонних компонентов сохранены.

## Code signing policy / предупреждение SmartScreen

Скриншот «Система Windows защитила ваш компьютер / неизвестный издатель» относится к репутации SmartScreen. Это отличается от обнаружения вируса антивирусным сканером.

24 октября 2026 года отправлена заявка на бесплатную подпись через SignPath Foundation; форма подтвердила отправку. Одобрение и производственный сертификат пока не получены. Этот релиз не объявляется подписанным, предупреждение SmartScreen пока может сохраняться.

Подготовлена интеграция SignPath в GitHub Actions: только собственные EXE/DLL, проверка подписей и пересчёт контрольных сумм после подписания. Включение ожидает одобрения SignPath и настройки аккаунта владельцем. Самоподписанные доверенные корневые сертификаты не устанавливаются, настройки SmartScreen и Defender не изменяются.

См. [Code signing policy](https://github.com/Rom4nIlyin/afterplay/blob/main/docs/CODE-SIGNING.md).
Планируемая после одобрения подпись: Free code signing provided by [SignPath.io](https://signpath.io), certificate by [SignPath Foundation](https://signpath.org).

## Проверка

51 Python-тест, отдельные тесты математики масштаба, нативное окно WebView2: реальные сообщения боковых кнопок и команд браузера, зум под курсором, сохранение выделения, обновление кадров, прокрутка, кнопка Проводника и раздельные действия проверки/установки обновления. Существующие тесты GIF и резервного восстановления обновлятора сохранены.

## Установка

Скачайте AFTERPLAY-1.7.0-Portable-Win64.zip и распакуйте всю папку. Для обновления установленной программы используйте «Настройки → Проверить обновления → Скачать и установить обновление». Записи и настройки сохраняются; прежние файлы программы копируются в backups.
