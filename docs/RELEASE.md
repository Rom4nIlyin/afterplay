# AFTERPLAY 1.14.5

Повторные нажатия сохранения больше не отклоняются: каждый запрос запоминает момент нажатия и выполняется по очереди. Повтор и обычная запись работают без аудиоустройств и автоматически подхватывают включённые в настройках звук и микрофон после подключения.

- **Сохранение во время записи:** до восьми запросов в очереди, защита буфера до окончания всех сохранений, ожидание очереди при полном выходе. Обычный повтор и быстрые клипы сохраняют свои правила длительности.
- **Меньше нагрузки на захват:** временный буфер остаётся в `data/replay-buffer`, а готовые видео — в выбранной папке. FFmpeg переносит сжатые потоки напрямую, без перекодирования и повторного прохода по всему MP4 при финализации.
- **Устройства можно подключить позже:** до подключения соответствующая дорожка тихая. Отключение, смена устройства по умолчанию и переподключение не требуют перезапуска записи.
- **Устойчивый звук:** системное аудио работает в отдельном контролируемом процессе. Непрерывный счётчик сэмплов устраняет короткие разрывы и перекрытия от колебаний временных меток WASAPI.
- **Совместимость:** сохранены изменения Windows 10 и Windows 11 из версии 1.14.4, существующие настройки, библиотека и видеозаписи.

## Установка и обновление

Скачай `AFTERPLAY-1.14.5-Portable-Win64.zip` из Assets. После остановки записи обнови программу через **Настройки → Проверить обновления** либо запусти из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор сохраняет пользовательские файлы и создаёт резервную копию. Сверь архив с файлом `.zip.sha256`.

[Проверки и ограничения](https://github.com/Rom4nIlyin/afterplay/blob/main/docs/VERIFICATION.md). Циклы подключения проверены на управляемых источниках, непрерывность захвата — также на реальном устройстве. Физическое переподключение гарнитуры и длительный игровой сеанс отдельно не проверялись.
