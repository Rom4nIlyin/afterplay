## Что нового в 1.3.1

- Жёлтая рамка вокруг записываемого окна или экрана выключена по умолчанию, включая обновление с 1.3.0.
- Добавлен переключатель **«Настройки» → «Захват» → «Показывать жёлтую рамку во время записи»**.
- Выбор сохраняется между запусками. Для изменения остановите запись и дождитесь экспорта; новая настройка применяется при следующем включении записи.

## Скачать и обновить

В Game Clips 1.3.0 откройте **«Настройки» → «Проверить обновления» → «Обновить и перезапустить»**. Записи и настройки сохраняются.

Для новой установки скачайте **Game-Clips-1.3.1-Portable-Win64.zip** из Assets, распакуйте папку целиком и запустите **Game Clips.exe**. Python, FFmpeg и автономный установщик WebView2 включены в комплект.

## Проверка

Автоматические тесты, настоящий WebView2 и захват тестового окна с включённой и выключенной рамкой. Сборка и публикация выполняются в GitHub Actions.
