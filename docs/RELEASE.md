# AFTERPLAY 1.16.2

Windows 10: плавная запись без просадки FPS в игре.

- **Запись окна и экрана на Windows 10 — 60 FPS.** Используется DXGI Desktop Duplication (как в OBS), без жёлтой рамки. Больше нет «слайд-шоу» в 10–20 кадров и просадки FPS в игре.
- Окно записывается там, где оно было при старте записи. Если передвинули окно — перезапустите повтор.
- Остальное из 1.16.1: звук отдельных приложений на Windows 10 2004+ и клавиша «Выключить или включить микрофон».

## Установка и обновление

Скачай `AFTERPLAY-1.16.2-Portable-Win64.zip` из Assets. После остановки записи обнови программу через **Настройки → Обновления** либо запусти из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор сохраняет пользовательские файлы и создаёт резервную копию. Сверь архив с файлом `.zip.sha256`.
