## Что нового в 1.3.0

- Новые окна появляются в списке автоматически каждые 3 секунды.
- Ранее выбранная игра подхватывается после перезапуска по пути EXE, с новым PID и HWND.
- В настройках появилась проверка версии GitHub и установка обновления с перезапуском, SHA-256, резервной копией и откатом при ошибке.
- Три темы: стандартная, тёмная и светлая. Доступные кнопки меняют цвет при наведении и нажатии.
- Создание ярлыка на рабочем столе, подготовка закрепления на панели задач через штатное меню Windows.
- Переключатель «Запускать автоматически при включении компьютера» для текущего пользователя Windows.

## Скачать и обновить

Скачайте **Game-Clips-1.3.0-Portable-Win64.zip** из Assets, распакуйте папку целиком и запустите **Game Clips.exe**. Python, FFmpeg и автономный WebView2 включены в комплект. Source code содержит только исходники.

Из версии 1.2.0 обновитесь распаковкой полного архива поверх программы **с сохранением папки data**. Начиная с 1.3.0 следующие обновления устанавливаются из раздела «Настройки» → «Проверить обновления».

Для панели задач нажмите соответствующую кнопку в настройках, затем по выделенному ярлыку в Проводнике — правой кнопкой → «Закрепить на панели задач». В Windows 11 может понадобиться «Показать дополнительные параметры».

Автозапуск включается отдельно и действует после входа пользователя в Windows. Запись включается вручную.

## Проверка

19 автоматических тестов, настоящий установщик .NET, откат при блокировке файла, сохранность тестовых записей и настроек, ярлыки и автозагрузка в изолированных папках. Новое окно и перезапуск процесса проверены через интерфейс. Проверены три темы и сохранение выбора. Полная сборка и публикация выполняются в GitHub Actions.
