# AFTERPLAY 1.7.1

Исправлена ошибка при полном выходе из программы: «Тип __System_Action...Dispatcher не помечен как сериализуемый».

Причиной было сохранение Python.NET состояния .NET для повторного запуска интерпретатора внутри того же процесса. Обработчик боковых кнопок мыши содержит Python-делегат, который нельзя сериализовать. Теперь загрузчик явно указывает Python.NET, что завершается весь процесс, и выполняет обычную очистку ресурсов без ненужного снимка для перезагрузки. Ошибки запуска не скрываются.

Добавлен нативный регрессионный тест: прежнее завершение действительно воспроизводит SerializationException с Action<Int32>, исправленное завершает Python.NET и подтверждает IsInitialized=False.

Проверки: 52 Python-теста, тесты масштаба дорожки и повторные полные выходы из настоящего AFTERPLAY.exe. Исправление также важно для установки обновлений, которая ожидает завершения прежнего процесса.

## Установка

Скачайте AFTERPLAY-1.7.1-Portable-Win64.zip или используйте «Настройки → Проверить обновления → Скачать и установить обновление». Записи, библиотека и настройки сохраняются; прежние файлы программы копируются в backups.
