# AFTERPLAY 1.11.2

Рыся, более удобный редактор и исправления запуска интерфейса.

- **Питомец Рыся:** включается в **Настройки → Показать питомца** и по умолчанию выключен. Кот гуляет по открытой вкладке, прыгает на блоки и кнопки, спит и умывается. Левый клик: сначала распушается, затем отпрыгивает в другое место. Правый клик или Enter: поглаживание и тихое мурчание. Звук можно отключить; выбор сохраняется. Во время просмотра видео, обучения и сворачивания питомец останавливается.
- **Звук редактора:** дорожки подготавливаются заранее и сохраняют общую позицию воспроизведения. Переключение больше не перезапускает загрузку каждой дорожки. AAC для предпросмотра копируется без повторного кодирования, если формат позволяет.
- **Порядок в интерфейсе:** выровнены чекбоксы и добавлены отступы между кнопками. «Открыть в папке», «Этот кадр — обложка» и «Удалить видео» находятся во вкладке **Экспорт** редактора.
- **Запуск после распаковки:** исправлена выдача CSS/JavaScript независимо от файловых ассоциаций Windows, увеличена очередь локального сервера, отключено устаревающее кэширование интерфейса. Добавлены проверка файлов, одна попытка восстановления неудачной загрузки и локальная диагностика в `data/logs`.
- **Совместимость Windows:** для старых сборок Windows 10 и недоступного Windows Graphics Capture добавлен резервный захват. Сборка рассчитана на Windows 10/11 x64; проверка каждой редакции и сборки Windows не выполнялась. В старых системах действуют ограничения самого WebView2 и системного API звука отдельных приложений.

Настройки оформления, папки, библиотека и горячие клавиши сохраняются. Исходные фотографии питомца и пользовательские записи в архив не включены. Источник записи мурчания указан в `app/ui/pets/CREDITS.md`.

## Установка и обновление

Скачайте `AFTERPLAY-1.11.2-Portable-Win64.zip` из Assets и распакуйте **весь архив** в новую папку. Для новой установки запустите `AFTERPLAY.exe`.

Для обновления используйте **Настройки → Проверить обновления** либо полностью выйдите из AFTERPLAY через меню трея и запустите из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор создаёт резервную копию и сохраняет библиотеку, настройки и записи. При другом расположении программы укажите его через `-Target`.

Контрольная сумма находится в соседнем файле `.zip.sha256`.
[Проверки](https://github.com/Rom4nIlyin/afterplay/blob/main/docs/VERIFICATION.md).
