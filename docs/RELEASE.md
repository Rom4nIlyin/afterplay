# AFTERPLAY 1.8.0

- Скорость просмотра 0,1–4×: ползунок, ручной ввод с точкой или запятой и быстрые кнопки 0,1 / 0,25 / 0,5 / 0,75 / 1 / 1,5 / 2×.
- Опциональный таймер `мм:сс.мс` в правом верхнем углу просмотра и экспорта MP4/GIF, от начала выделенного отрезка. Скорость просмотра не изменяет скорость экспорта.
- Полный экран включается штатной кнопкой плеера. Дублирующая кнопка убрана; таймер виден поверх видео, Escape возвращает к редактору.
- `Ctrl+Alt+F8` показывает и скрывает окно в трей; сочетание настраивается. Повторный запуск ярлыка открывает уже работающий экземпляр.
- В GPU-захвате сохранены интервалы временных меток WGC/DXGI. Привязка к началу аудиозаписи выполняется на первом кадре до входной очереди, без переназначения последующих кадров по времени чтения. Задержки очереди больше не растягивают видеодорожку относительно аудио. Изменение применяется к новым записям; существующие файлы не переписываются.
- `.afterplay-buffer`, ошибочное написание `.afterpaly-buffer`, временные стадии и незавершённые файлы исключены из индексации. Ранее попавшие в индекс сегменты тоже скрываются, без удаления файлов.
- Подключённую папку можно отключить. Файлы и заметки сохраняются; повторное подключение возвращает записи. Вложенная папка, подключённая отдельно, остаётся доступной.
- Прокрутка открытого редактора не передаётся библиотеке на фоне.
- Убран лишний блок «Данные и журнал / Папка экспорта» из настроек.
- Стандартная и светлая темы сохранены. Тёмная тема получила отдельную палитру вместо дублирования стандартной.

## Проверки

56 Python-тестов и тесты масштаба дорожки. Регрессионный тест задерживает подачу кадров вдвое и проверяет сохранение исходной длительности видео. Контрольная запись отдельного тестового окна: 2560×1440, 60 FPS, GPU-захват и звук процесса; после 75 секунд записи сохранён последний минутный фрагмент. Максимальное измеренное смещение звуковых импульсов относительно вспышек — 44 мс, потерянных из-за опоздания аудиокадров нет. Игра для проверки не запускалась; этот тест не подтверждает поведение многочасового игрового сеанса.

Подробности UI и нативных проверок — [VERIFICATION.md](https://github.com/Rom4nIlyin/afterplay/blob/main/docs/VERIFICATION.md).

## Установка

Скачайте `AFTERPLAY-1.8.0-Portable-Win64.zip` или используйте встроенную проверку обновлений. Записи, библиотека и настройки сохраняются, предыдущие файлы программы копируются в backups.
