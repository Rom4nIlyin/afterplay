# AFTERPLAY 1.15.4

Библиотека сама замечает переименованные файлы, прогресс обновления виден, запись нажатий убрана.

- **Библиотека:** видео, переименованные, перемещённые или добавленные вне AFTERPLAY, появляются сами через несколько секунд. Переименованное видео остаётся той же записью — метки, избранное, игра и превью сохраняются.
- **Запись нажатий клавиш убрана:** рядом с видео больше не появляются файлы `.inputs.json`.
- **Прогресс фоновых задач:** загрузка обновления в процентах и мегабайтах, индексация библиотеки, экспорт с кнопкой «Отменить» — видны с любого экрана.
- **Микрофон:** если он не найден (например, Bluetooth-гарнитура не подключена), панель записи предупреждает «⚠ Микрофон не подключён».
- **Просмотр:** переключение звуковых дорожек больше не нагружает компьютер.
- **Громкость и качество экспорта** запоминаются между запусками.
- Много исправлений интерфейса: даты и склонения в библиотеке, подписи и подсказки у недоступных кнопок, точные вкладки настроек, имя файла при экспорте.

## Установка и обновление

Скачай `AFTERPLAY-1.15.4-Portable-Win64.zip` из Assets. После остановки записи обнови программу через **Настройки → Обновления** либо запусти из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор сохраняет пользовательские файлы и создаёт резервную копию. Сверь архив с файлом `.zip.sha256`.
