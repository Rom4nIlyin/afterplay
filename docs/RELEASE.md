# AFTERPLAY 1.16.0

Журнал и отчёт о проблеме в один клик.

- **Настройки → Журнал** показывают последние события и ошибки программы.
- **Скопировать** кладёт отчёт в буфер обмена, **Отправить разработчику** отправляет его на GitHub — можно добавить пару слов о том, что случилось. Повторы одной и той же ошибки собираются в одну запись.
- Перед отправкой из отчёта удаляются пути к файлам, имя пользователя и компьютера, названия клипов, окон и профилей. Отчёт можно просмотреть целиком кнопкой «Показать».

## Установка и обновление

Скачай `AFTERPLAY-1.16.0-Portable-Win64.zip` из Assets. После остановки записи обнови программу через **Настройки → Обновления** либо запусти из новой распакованной папки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор сохраняет пользовательские файлы и создаёт резервную копию. Сверь архив с файлом `.zip.sha256`.
