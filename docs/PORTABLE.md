# AFTERPLAY 1.10.0

Запуск: **AFTERPLAY.exe**.

Распакуйте весь архив. Сохраняйте приложение и его папки вместе.
Python и FFmpeg уже входят в комплект.

| Файл или папка | Что внутри |
| --- | --- |
| `AFTERPLAY.exe` | Запуск приложения, иконка для ярлыка |
| `app` | Компоненты, интерфейс, Python, FFmpeg, обновлятор |
| `docs` | Руководство, изменения и лицензии |
| `data` | Настройки, библиотека, записи, экспорт и журналы; создаётся при запуске |
| `backups` | Предыдущие файлы программы; создаётся при обновлении |

Записи в выбранной вами внешней папке остаются в этой папке.
Подробное руководство: [docs/USER-GUIDE.md](docs/USER-GUIDE.md).

## Обновление с 1.8.3 и более ранних версий

Для перехода на новую структуру один раз используйте обновлятор из нового архива.
Старый встроенный обновлятор не понимает новую структуру и отклонит архив до установки.

1. Распакуйте новый архив в отдельную папку.
2. Полностью закройте старый AFTERPLAY через меню трея, дождавшись сохранения.
3. Откройте PowerShell в новой папке и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор сохранит прежние файлы в `backups/update-*`, установит новую структуру
и запустит AFTERPLAY. Настройки, горячие клавиши, библиотека и записи сохраняются.
Изменённые вручную и неизвестные файлы остаются на месте. Старые неизменённые
служебные файлы переносятся в резервную копию. Пустые старые папки убираются.
Не копируйте новый архив поверх старой папки вручную.

Начиная с 1.8.4 последующие обновления снова доступны из настроек приложения.
Для создания ярлыков используйте настройки AFTERPLAY или `app/Install-Shortcuts.ps1`.


## Запись и монтаж

Профили редактируются прямо на странице «Повтор». По умолчанию записываются весь экран и звук устройства. В монтаже доступны точные кадры, обрезка, звуковые дорожки и экспорт. Руководство: STUDIO.md.

Оформление, наборы, фоны и английский язык: [docs/CUSTOMIZATION.md](docs/CUSTOMIZATION.md).
