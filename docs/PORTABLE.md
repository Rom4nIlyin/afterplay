# AFTERPLAY

Запуск: **AFTERPLAY.exe**.

Распакуйте весь архив и держите программу и её папки вместе. Python и FFmpeg уже входят в комплект.

| Файл или папка | Что внутри |
| --- | --- |
| `AFTERPLAY.exe` | Запуск программы, иконка для ярлыка |
| `app` | Компоненты, интерфейс, Python, FFmpeg, обновлятор |
| `docs` | Руководство, список изменений и лицензии |
| `data` | Настройки, библиотека и журналы; создаётся при запуске |
| `backups` | Предыдущие файлы программы; создаётся при обновлении |

Записи хранятся в папке, выбранной в настройках.
Руководство: [docs/USER-GUIDE.md](docs/USER-GUIDE.md).

## Обновление

Обычно достаточно **Настройки → Обновления**.

Для установок 1.8.3 и старше один раз используйте обновлятор из нового архива:

1. Распакуйте новый архив в отдельную папку.
2. Полностью закройте старый AFTERPLAY через меню трея, дождавшись сохранения.
3. Откройте PowerShell в новой папке и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Update-Existing.ps1 -Target "C:\AFTERPLAY Portable"
```

Обновлятор сохранит прежние файлы в `backups/update-*` и запустит AFTERPLAY. Настройки, горячие клавиши, библиотека и записи сохраняются. Не копируйте новый архив поверх старой папки вручную.

Ярлыки создаются в настройках AFTERPLAY или скриптом `app/Install-Shortcuts.ps1`.
