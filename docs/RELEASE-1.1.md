# Game Clips 1.1 — звук на выбор и буфер до 30 минут

Локальная видеотека и мгновенные повторы для Windows x64.

## Новое

- Четыре режима записи звука: всё устройство, только выбранная игра/приложение,
  всё кроме выбранного приложения и без звука.
- Длительность буфера: 1, 3, 5, 10, 15, 20 или 30 минут.
- H.264 через CPU при недоступности NVIDIA NVENC.
- Портативная сборка со встроенными Python, FFmpeg и автономным WebView2 Installer.

## Установка

Скачайте **Game-Clips-1.1-Portable-Win64.zip**, распакуйте целиком и запустите
**Game Clips.exe**. Python и FFmpeg отдельно не нужны. Если WebView2 отсутствует,
программа установит его из комплекта. В архиве нет личных видео и настроек.

Запустите игру, выберите звук и длительность в разделе «Повтор», включите буфер.
**Ctrl + Alt + F10** сохраняет последние выбранные минуты в `data/exports`.
Микрофон не записывается.

## Совместимость

Windows 10 1903+ / Windows 11 x64, .NET Framework 4.8. Захват и исключение отдельного
приложения требуют Windows build 20348+; на обычной Windows 10 22H2 доступны
системный звук выбранного устройства и запись без звука.

Программа не подписана сертификатом издателя. Источники и инструкции сборки находятся
в репозитории. Подробности проверки и известные ограничения — `docs/VERIFICATION.md`.
