# AFTERPLAY 1.4.1 — локальная проверка 2026-10-24

- 35 автоматических тестов: настройки, пути записи, совместимость обновлений, конфликты Win32-клавиш, автоматика, синхронизация и качество захвата.
- Нативный AFTERPLAY.exe / WebView2: запуск в трее, обе темы, галерея и список; переключение мышью.
- Реальная шкала из 12 кадров; перетаскивание отдельной границы и всего участка проверено мышью.
- Экспорт 1,2–3,8 с создал MP4 длиной 2,6 с в выбранной папке с кириллицей и пробелами; файл полностью декодирован FFmpeg.
- Автоматическое распознавание тестового EXE, запись его окна со звуком процесса, сохранение зарегистрированной горячей клавишей и при закрытии. Проверены видеопоток, AAC и полное декодирование сохранённых MP4.
- На Windows 11 build 26300 исправлено ложное определение build 9200 внутри нативного хоста без манифеста. Проверка версии теперь использует RtlGetVersion; хост содержит манифест Windows 10/11.

Игра не запускалась. Наличие аудиодорожки проверено; тестовое окно было без звукового содержимого. Поведение конкретной игры, длительный игровой сеанс и чистая виртуальная машина этой проверкой не подтверждаются. FFmpeg и WebView2 остаются дочерними процессами: единая строка всех ресурсов в Диспетчере задач не гарантируется.

## Дополнительная проверка исправления запуска

Ошибка запуска воспроизведена на распакованной скачанной версии: у `Python.Runtime.dll`
был поток `Zone.Identifier` с `ZoneId=3`, и `import clr` завершался ошибкой.
После проверки хешей и подготовки семи собственных .NET-компонентов запуск прошёл.
Исправленная папка пользователя проверена через настоящее окно WebView2.

Дополнительно новый ZIP распакован в отдельный путь, всем файлам добавлена такая же
метка скачивания. До исправления подтверждена ошибка CLR, затем исправленное приложение
успешно открыло скрытое окно и проверило элементы управления. Метки посторонних файлов
остались на месте. Изменённая DLL отклоняется, частичная подготовка повреждённого
комплекта не выполняется. Системные политики Windows не менялись.

Регрессионные проверки: `python -m unittest discover -s tests` на Windows/NTFS.
