# Проверка версии 1.1

Проверки выполнены 23 октября 2026 года на Windows x64.

| Проверка | Результат |
| --- | --- |
| Самостоятельный Python из архива | Импорт зависимостей и запуск FFmpeg без системного Python |
| Перенос | EXE запущен из заново распакованного архива в пути с кириллицей и пробелами |
| Интерфейс WebView2 | Отображаются четыре режима звука и семь вариантов длительности |
| Значения длительности | Сохраняются 1, 3, 5, 10, 15, 20 и 30 минут; неверные значения отклоняются |
| Скользящий буфер | После записи дольше минуты сохраняются последние 60,06 секунды |
| Готовый MP4 | 2560 × 1440, одна аудиодорожка, ненулевой размер и корректная длительность |
| Изоляция приложения | Два независимых источника 440/880 Гц; второй исключён из захвата выбранного процесса |
| Изоляция в конечном файле | Проверена декодированием аудио из сохранённого MP4 |
| Исключение приложения | Выбранный процесс исключён; второй источник слышен |
| Без звука | Сохраняется MP4 без аудиодорожки |
| CPU H.264 | Проверены GDI и Desktop Duplication |
| Защита настроек | Изменение параметров во время записи отклоняется |
| Совместимость настроек | Старый режим «Без звука» переносится без включения аудио |
| Архив | Все записи ZIP прочитаны с проверкой CRC |
| WebView2 Installer | Действительная цифровая подпись Microsoft Corporation |
| Скрипт сборки | Полная установка закреплённых зависимостей, компиляция C#, создание ZIP и проверка его CRC |
| Свежая сборка из исходников | Проверка окна и элементов управления через встроенный Python/WebView2 прошла успешно |

Отдельная чистая виртуальная машина Windows не использовалась. Установка WebView2
на системе без него не запускалась. Полная 30-минутная запись и запись внутри
конкретной игры не выполнялись. Для длинных буферов проверены настройки и выбор
временного диапазона; сквозная запись проверена с минутным буфером.

При проблемах приложите к issue версию Windows, режим звука, выбранную длительность,
FPS, битрейт, модель GPU и относящийся к ошибке журнал из `data/logs`.
Перед публикацией журнала проверьте его на личные пути и названия файлов.
