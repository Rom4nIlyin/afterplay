# Проверка версии 1.2.0

## Захват и синхронизация 1.2.0

Проверено 23 октября 2026 на Windows x64, NVIDIA RTX 3080.

| Проверка | Результат |
| --- | --- |
| Изолированное окно | Windows Graphics Capture по HWND; сохранён MP4 с размерами окна |
| Перекрытие окна | Второе сплошное пурпурное окно полностью закрывает источник; его цвет не появился в декодированных кадрах MP4 |
| Монитор и масштаб | 2560 × 1440 → 1920 × 1080, 60 FPS, системный WASAPI-звук, MP4 с AAC |
| Без звука | MP4 выбранного окна без аудиодорожки |
| Аудио процесса | WASAPI process loopback с QPC-метками; один AAC-поток |
| Минутный повтор | После 74 секунд работы сохранено 60,03 секунды MP4 с NVENC |
| Синхронизация | Тестовое окно со вспышками и звуком каждые 2 секунды; декодирован конечный MP4 |
| Разброс A/V | От −27 до +43 мс на минутном файле; нарастающей задержки нет |
| Режимы кодирования | CQ/CRF, VBR, CBR проверены реальным FFmpeg для NVENC и libx264 |
| Интерфейс | Настройки сохраняются; WebView2 smoke проверяет звук, буфер, FPS, источник, качество, разрешение и сдвиг |
| Модульные проверки | 11 тестов: частичные/опоздавшие аудиопакеты, сдвиг, длительности, качество и подготовка DLL |

Тестовый источник — отдельное WinForms-окно с движущимся узором, белыми вспышками
и короткими звуковыми импульсами. Время вспышек измерялось по яркости декодированных
кадров, звука — по RMS декодированного AAC с шагом 10 мс. Небольшой разброс включает
планировщик Windows, обновление окна, захват и звуковое устройство.

Эта проверка не подтверждает работу конкретной игры в эксклюзивном полном экране.
Наличие потерь сжатия зависит от сцены и настроек. Изменения улучшают последующие
записи; предоставленные исходные клипы не изменялись.

## Дополнительная проверка исправления запуска

Ошибка запуска воспроизведена на распакованной скачанной версии: у `Python.Runtime.dll`
был поток `Zone.Identifier` с `ZoneId=3`, и `import clr` завершался ошибкой.
После проверки хешей и подготовки семи собственных .NET-компонентов запуск прошёл.
Исправленная папка пользователя проверена через настоящее окно WebView2.

Дополнительно новый ZIP распакован в отдельный путь, всем файлам добавлена такая же
метка скачивания. До исправления подтверждена ошибка CLR, затем исправленное приложение
успешно открыло скрытое окно и проверило элементы управления. Метки посторонних файлов
остались на месте. Изменённая DLL отклоняется, частичная подготовка повреждённого
комплекта не выполняется. Системные политики Windows не менялись.

Регрессионные проверки: `python -m unittest discover -s tests` на Windows/NTFS.

Отдельная чистая виртуальная машина Windows не использовалась. Установка WebView2
на системе без него не запускалась. Полная 30-минутная запись и запись внутри
конкретной игры не выполнялись. Для длинных буферов проверены настройки и выбор
временного диапазона; сквозная запись проверена с минутным буфером.

При проблемах приложите к issue версию Windows, режим звука, выбранную длительность,
FPS, битрейт, модель GPU и относящийся к ошибке журнал из `data/logs`.
Перед публикацией журнала проверьте его на личные пути и названия файлов.
