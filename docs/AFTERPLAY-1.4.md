# AFTERPLAY 1.4

Версия 1.4 получила логотип Loop и обновлённый интерфейс.

## Где находятся новые возможности

Откройте **Настройки → Автозапись игр и приложений**. Включите переключатель, добавьте запущенное приложение из списка или выберите его исполняемый файл `.exe`. Можно временно отключить отдельный пункт, не удаляя его из списка.

Программа распознаёт приложение по полному пути и ждёт готовое видимое окно. Старый PID после перезапуска не используется. Записывается только выбранное окно, с качеством и режимом звука из раздела «Повтор». При нескольких доступных приложениях приоритет у первого в списке. Открытые окна проверяются раз в секунду только при включённой автозаписи.

Это автоматическое включение **буфера мгновенного повтора**, а не непрерывная запись всего сеанса. Нужные последние 1–30 минут сохраняются по выбранной клавише. Опция сохранения при закрытии приложения включена по умолчанию. Она сохраняет последние минуты, затем выключает захват. Закрытие AFTERPLAY и отключение автозаписи также завершают принадлежащую автоматике запись.

Ручная запись не перехватывается автоматикой. После ручной остановки текущее приложение пропускается до его следующего запуска. Если свёрнутое окно перестало отдавать кадры, захват останавливается; при появлении готового окна возможен новый запуск. Ошибки запуска не повторяются каждую секунду для того же процесса.

В разделе **Настройки → Горячие клавиши** нажмите на поле, введите сочетание и сохраните:

- Сохранить последние минуты — по умолчанию **Ctrl+Alt+F10**.
- Включить/выключить автозапись — по умолчанию **Ctrl+Alt+F9**.

Если сочетание занято, появится сообщение, а прежние рабочие клавиши останутся зарегистрированы. Поддерживаются Ctrl/Alt/Shift с буквами, цифрами и служебными клавишами, а также отдельные F-клавиши. F12 зарезервирована Windows.

Тёмная и светлая темы находятся в **Настройки → Тема интерфейса**. Стандартная тема использует новую тёмную палитру. Выбор сохраняется.

## Запуск и процессы

Запускайте **AFTERPLAY.exe**. Ярлык автозагрузки содержит `--autostart`: при входе в Windows окно остаётся скрытым, значок доступен в трее. Обычный запуск с рабочего стола открывает окно. Настройка действия крестика сохранена.

Python встроен в процесс AFTERPLAY.exe и не запускается отдельным pythonw.exe. EXE содержит название, версию и выбранную иконку. FFmpeg и WebView2 остаются дочерними процессами. Windows может отображать их отдельными группами; сведение всех счётчиков ресурсов в одну строку Диспетчера задач этой версией не обеспечивается.

Папка `data`, исходные видео и библиотека не переносятся и не переименовываются. Ярлыки ведут на AFTERPLAY.exe.

## Дополнения 1.4.1

Над библиотекой доступны «Галерея» и «Список». Настройки вида сохраняются. В редакторе клипа выберите подсвеченный участок на шкале с кадрами, передвиньте границы или задайте точное время. Кнопка «Посмотреть выделенное» воспроизводит только выбранный фрагмент. Экспорт создаёт отдельный MP4, исходник не изменяется.

В настройках появилась папка сохранения. Она применяется к новым повторам, обрезанным клипам и временным сегментам буфера. Старые файлы не перемещаются и остаются доступны по прежним путям. Для смены остановите запись и дождитесь экспорта. Кнопка «По умолчанию» возвращает data/exports и data/replay-buffer.
