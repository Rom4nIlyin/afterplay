# Интерфейс AFTERPLAY

HTML, CSS, JavaScript, шрифты и иконки окна программы. `index.html` подключает `ag-app.js`, словари `en-catalog.js` и `ko-catalog.js` и движок переводов `i18n.js`. Файлы раздаёт локальный сервер приложения.

Словари правятся в `en.json` и `ko.json`, каталоги пересобирает `python scripts/build_translations.py`.
